# NOMAD the arcade game

2D игра на Pygame, где игрок сражается с врагами, собирает аптечки и бустеры выносливости.

## Особенности

- Динамичный геймплей с врагами разных типов
- Система выносливости и здоровья
- Различные бустеры и аптечки

## Установка

1. Клонируй репозиторий:
```bash
git clone https://github.com/ObiiOne/first-small-arcade-game-.git
```
2. Установи зависимости:
```bash
pip install -r requirements.txt
```
3. Запусти игру:
```bash
python game.py
```

## Управление
- Стрелки - движение
- Пробел - атака
- ESC - выход в меню

## Требования
- Python 3.6+
- Pygame 2.0+
